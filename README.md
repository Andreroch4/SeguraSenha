# SeguraSenha

Ferramenta gratuita e educativa que ajuda as pessoas a criar senhas fortes e adotar boas práticas de segurança digital.

## Como usar

Abra o arquivo `index.html` no navegador (dois cliques). Não precisa de internet, instalação nem servidor.

## Estrutura

```
AtividadeExtensao/
├── index.html      → conteúdo e estrutura da página
├── css/estilo.css  → aparência (cores, layout, versão para celular)
└── js/script.js    → interatividade (verificador, gerador, checklist, quiz)
```

## Funcionalidades

- **Verificador de senha**: mostra força, tamanho (curta, média ou longa), tempo estimado para ser descoberta, critérios atendidos e sugestões de melhoria.
- **O que torna uma senha forte**: explicação dos fatores (tamanho, variedade, imprevisibilidade, uso único, sigilo).
- **Gerador de frase-senha**: cria senhas longas e fáceis de lembrar.
- **Boas práticas**: verificação em duas etapas, gerenciador de senhas, golpes, Wi-Fi público e um checklist interativo.
- **Quiz**: perguntas rápidas para fixar o conteúdo.

## Classificação por tamanho

| Categoria | Tamanho          | Situação       |
|-----------|------------------|----------------|
| Curta     | até 7 caracteres | Evitar         |
| Média     | 8 a 11           | Aceitável      |
| Longa     | 12 ou mais       | Recomendado    |

## Privacidade

Toda a análise acontece no próprio navegador. Nenhuma senha é salva ou enviada para a internet.
